# Changelog

## 0.1.0

First public release.

- Works with chrony, ntpd (NTP control protocol) and any NTP server (basic view).
- Optional GPS panels: satellite map, sky view, fix and PPS data.
- Public server cross-check and upstream health checks.
- Browser clock vs NTP clock comparison.
- History charts, event log, optional basic auth, position privacy controls.
- Docker images for amd64 and arm64.
